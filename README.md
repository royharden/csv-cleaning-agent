# CSV Cleaning Agent

A local-first CSV/TSV review app: propose a plan, inspect cumulative previews, approve changes, apply an append-only journal, undo, and export independently checkable artifacts. React 18, TypeScript and Vite source is present, with eight pure transforms, rules/fixture/live planner adapters, two Deno edge functions and a synthetic evaluation harness.

**Construction only — runtime unverified (2026-10-24).** Nothing has been installed, typechecked, linted, tested, generated, built, served, evaluated, called at a provider, deployed or published in this construction run. Authored tests are not passing tests. No measured results exist; performance/accuracy/cost claims must come from future `results/results.md` and its JSONL receipts. The inner repository is local only, has no remote, and has never been pushed.

## Data boundary and limitations

Raw user CSV bytes, full table/profile, previews, edits, journal and rulings stay in the browser/IndexedDB and exported local files. Mock planners make no model calls; loading the bundled sample fetches an app asset. In live planning only the displayed bounded profile travels to the edge function and provider: screened labels, aggregate statistics and at most eight shared strings per included column, each at most 40 characters. Screening examines full originals before clipping. Exclusions remove the column from outbound disclosure; aggregate duplicate counts still describe whole rows. Screening is a finite heuristic, not anonymization. See [PRIVACY](docs/PRIVACY.md).

Jev is **experimental and optional**, not default-on: its pairs/siblings use only screened, untruncated disclosed values. The shared eight-value cap may constrain recall below rules, which sees all values locally. Full-vocabulary alias recall is the inclusion gate; eligible-candidate recall is a diagnostic. No gate, robustness, price or provider compatibility result exists. Wider disclosure is not built. The synthetic Node-only `llm_direct` comparator sends synthetic cells (maximum matched 200×6); it is never a route for a user's CSV.

Live needs anonymous user Auth and a separate owner-configured **hard** provider/project cap. `VITE_LIVE_ENABLED=1` is public owner attestation, not enforcement; browser call records are in-memory with unknown billing, not a durable/global spend meter. Scripted anonymous sign-ins can spend up to the external cap. Node live eval has a separate serial 5 USD reservation boundary, dated owner prices and unknown-usage stop; it is not a cloud cap. See [BOLT-HANDOFF](BOLT-HANDOFF.md) and [EVAL](docs/EVAL.md).

Input limits: 5,000,000 bytes, 20,000 data records, 60 columns. Missing ragged positions remain missing. Export preserves uniform detected record terminators; **mixed terminators normalize to the detected majority** (spec narrowing), and quoting is reserialized. windows-1252 inputs export as UTF-8 with notice. Only the original blob preserves exact input bytes. [VOCABULARY](docs/VOCABULARY.md) records exact constants; [LIMITATIONS](docs/LIMITATIONS.md) separates design limits from future measured failures.
